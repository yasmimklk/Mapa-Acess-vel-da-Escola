
# 🏫 Mapa Acessível da Escola

## Sobre o projeto

O projeto Mapa Acessível da Escola foi desenvolvido utilizando HTML5 e CSS3.

O objetivo é facilitar a localização dos ambientes escolares por meio de uma página simples e organizada.

O mapa apresenta oito espaços da escola, acompanhados de símbolos, nomes e descrições.

O projeto foi desenvolvido pensando na acessibilidade, inclusão e facilidade de navegação.

## Ambientes apresentados

1. 🏫 Entrada
2. 🏢 Secretaria
3. 📚 Sala de aula
4. 📖 Biblioteca
5. 🚻 Banheiro
6. 🍽️ Refeitório
7. 🌳 Pátio
8. 👩‍🏫 Sala dos professores

## Tecnologias utilizadas

- HTML5
- CSS3
- GitHub
- GitHub Pages

## Práticas de acessibilidade

- Informações objetivas.
- Títulos claros e organizados.
- Bom contraste entre texto e fundo.
- Fonte de fácil leitura.
- Espaçamento adequado.
- Símbolos acompanhados de textos.
- Menu de navegação.
- Layout responsivo para celulares.
- Navegação pelo teclado com foco visível.
- Poucas cores e elementos visuais.

## Objetivo

Desenvolver uma interface que ajude estudantes,
professores e visitantes a encontrar os espaços
da escola de maneira simples e acessível.

## Autor

Projeto desenvolvido como atividade escolar.
